# **App Name**: CloudVault

## Core Features:

- File Display: Display all files in a grid or list view with details such as name, size, and modification date.
- File Upload: Allow users to upload files from their local devices.
- File Search: Enable users to search for files by name.
- File Sorting: Implement sorting options to arrange files by name, size, or modification date.
- Category Navigation: Provide a navigation sidebar for accessing different file categories (e.g., All Files, Favorites, Photos, Documents).
- Storage Monitoring: Track and display the used storage space and total storage limit.

## Style Guidelines:

- Background color: Dark grey (#121212) to create a modern and immersive experience.
- Primary color: Light grey (#e0e0e0) for text and icons to ensure readability against the dark background.
- Accent color: Soft blue (#90caf9) to highlight interactive elements and call-to-actions.
- Font: 'Inter', a sans-serif font, for both headlines and body text due to its clean and modern appearance, suitable for UI elements.
- Use minimalistic and consistent icons for file categories and actions.
- Maintain a clean and organized layout with a clear separation between the navigation sidebar and the main file display area.
